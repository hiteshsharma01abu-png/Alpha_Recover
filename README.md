# Alpha Recover

Frontend for **Alpha Recover** — online data recovery training and services from Ahmedabad.

**Project folder:** `Alpha Recover`  
**Live site:** https://recova-sand.vercel.app  
**Vercel project:** `recova` (hosting slug; app brand is Alpha Recover)

## Run

```bash
cd "Alpha Recover"
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Local Vite dev server |
| `npm run build` | Typecheck + production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Oxlint |

## Stack (UI only)

- Vite + React + TypeScript
- React Router
- Custom CSS (no UI kit)

Auth, payments, and the training portal backend are not wired yet — forms are UI stubs.
